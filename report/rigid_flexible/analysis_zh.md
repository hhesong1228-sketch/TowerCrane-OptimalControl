# 同工况刚性梁与柔性梁对照

## 模型与工况

基准为当前修正后的 continuum 默认模型：塔身和吊臂各两阶 Euler–Bernoulli 模态，三个 ALE-ANCF 吊索单元。对照令 nTower=nJib=0，去除所有结构弹性自由度，吊点位置为 [x(t),0]；吊索单元、材料流动惯性、载荷、约束及积分精度保持一致。刚性框架固定在地基，结构自重由地基承担，不再产生弹性变形。

两者均为 0–10 s，小车 1–5 s 从 2.0 m 移至 2.4 m，吊索 2–8 s 从 2.0 m 收至 1.4 m，输入均为五次平滑曲线。吊物 5 kg，小车 20 kg，初始弦角 2°，初速度为零。两模型分别从各自结构静平衡位置出发，再施加相同初始摆角；因此初始吊物绝对位置不同。竖直坐标正向向下。

## 结果与柔性梁的必要性

| 指标 | 柔性与刚性结果的最大绝对差 |
|---|---:|
| 吊物水平位置 | 96.91 mm |
| 吊物竖直位置 | 148.77 mm |
| 扣除各自初始位置后的水平运动 | 约 14.7 mm |
| 扣除各自初始位置后的竖直运动 | 约 44.1 mm |
| 吊索弦角 | 0.1563° |
| 吊点竖直反力 | 0.2832 N |
| 小车驱动力（沿小车坐标的广义力） | 18.945 N |

初始位置偏差约为水平 82.2 mm、竖直 104.6 mm。因此绝对位置差主要包含结构静挠度，但移动和收绳过程中偏差继续变化，扣除初始偏移后仍存在厘米量级运动误差。需要预测厘米级吊物绝对位置、吊点变形或小车驱动力时，本工况下必须考虑梁柔性。柔性模型中的吊臂斜率还使重力沿小车坐标产生广义力，故驱动力差不能全部解释为结构振动。

柔性与刚性模型的峰值弦角分别约为 2.116° 和 2.138°，峰值很接近，但相同时刻最大角度差为 0.1563°（相对柔性模型峰值约 7.4%）。8–10 s 的最大绝对残余摆角分别为 0.8676° 和 0.9324°。是否需要柔性梁取决于摆角控制的精度目标，不能仅凭峰值接近认定两模型等价。

竖直吊点反力峰值分别为 51.683 N 和 51.514 N，同一时刻最大差约占柔性峰值的 0.55%。若只关注本工况的粗略吊点竖直载荷，刚性近似可能足够，不能由本次结果声称所有指标均强烈依赖梁柔性。

## 数值检查与适用边界

两模型均完成完整 10 s；最大连接位置约束误差分别为 6.20e-12 m 和 1.80e-12 m，方程残差低于 3e-14，采样吊索最小轴向力分别为 48.471 N 和 48.529 N，未出现松索。刚性约化的几何、质量矩阵正定性、约束秩、初始连接和力平衡检查通过；原有 16 阶梁模态正交性检查通过。

本次严格沿用当前默认两阶梁、三段吊索，不是新一轮模态或吊索网格收敛证明。已有结构验证指出有限阶梁模型存在截断误差，故表中数值应视为当前离散模型的对照，而非实际塔吊的标定精度。示例参数尚未实机标定。这里量化了采用刚性框架遗漏的效应，未预设工程验收阈值。
