# 二维 ALE-ANCF 变长度柔性绳模型

## 1. 新增了什么

在已有小车—竖向柔性支撑—吊物模型中，把无质量轴向弹簧替换为具有分布质量、轴向应变能和弯曲应变能的二维 ALE-ANCF 绳单元。MATLAB 入口为 `matlab/tower_crane_aleancf.m`，原降阶模型仍可独立运行。

参考 Li et al. (2022), *Multibody system dynamic analysis and payload swing control of tower crane*, 236(3), 407–421, [DOI:10.1177/14644193221101994](https://doi.org/10.1177/14644193221101994)。对应论文式 (1)–(18) 的插值、材料速度/加速度、弹性能和惯性力框架。

**实现范围：二维、给定材料坐标运动、固定单元数量的 ALE-ANCF。** 论文采用一个变长度单元与多个固定长度单元，并进行拆分/合并；这里所有单元按总绳长同比调整，单元数量固定。这是 ALE 网格选择上的简化，并非把普通 ANCF 的长度参数直接改成时间函数。代码明确保留固定材料坐标下的形函数时间导数与附加惯性。

塔身/吊臂仍为一个竖向集总弹簧阻尼器，未替换为论文的梁有限元。未实现回转、卷筒接触、卷扬电机、消摆控制、自动重网格和松绳冲击。示例参数不是论文参数，结果不是论文数值复现。

## 2. 节点、材料坐标与插值

坐标水平向右、竖直向下。每个二维节点具有四个机械坐标：

```text
q_i = [x_i, y_i, x_{s,i}, y_{s,i}]^T
```

这里斜率是位置对**未伸长材料坐标 s**的导数，不能当作单位切向量强制归一化，其模长包含轴向应变。

单元机械坐标为 `q_e=[r_1; r_{s,1}; r_2; r_{s,2}]`，共八个。完整二维 ALE 节点还包含材料坐标 `s_1,s_2`，即每单元十个坐标；本实现把这两个坐标作为给定函数消去，不将它们当作未知量积分。

对于 N 个单元：

```text
s_i(t) = (-1+i/N) L(t),  i=0,...,N
s_0=-L(t), s_N=0
l_e=s_{i+1}-s_i=L(t)/N
```

吊物端固定在材料坐标 `s=0`，表示吊物连接同一个绳材料端点；收绳时顶端 `s_0` 增大，材料从顶端离开计算域。内部节点随网格移动，不跟踪固定材料点。当前只适合有限、正长度的收放绳行程。

令 `ξ=(s-s_1)/l`：

```text
H1=1-3ξ²+2ξ³, H2=ξ-2ξ²+ξ³
H3=3ξ²-2ξ³,   H4=-ξ²+ξ³
N=[H1 I2, l H2 I2, H3 I2, l H4 I2]
r(s,t)=N q_e(t)
B=N_s, C=N_ss
```

相邻单元共享位置和材料斜率，保证中心线 C1 连续。顶端位置与小车/支撑位置共享坐标；底端位置与吊物位置共享坐标。两端斜率自由，对应无外加端弯矩；没有把顶部斜率强制固定为竖直方向。

## 3. ALE 材料速度与惯性

材料导数必须在 s 固定时计算：

```text
ξ̇|s = -(ṡ_1+ξ l̇)/l
ξ̈|s = -(s̈_1+ξ l̈+2 ξ̇ l̇)/l
v_material = N q̇_e + N_t q_e
a_material = N q̈_e + 2 N_t q̇_e + N_tt q_e
```

`shape.m` 用链式法则解析计算 `N_t,N_tt`。因此收放绳时，节点速度与经过该位置的材料速度一般不同。

材料坐标已给定后，机械方程为：

```text
M_e q̈_e + Q_elastic + Q_ALE = Q_gravity + Q_boundary
M_e = ∫ ρA N^T N ds
Q_ALE = ∫ ρA N^T (2N_t q̇_e + N_tt q_e) ds
```

第二项包括规定材料坐标加速度所产生的惯性贡献；它对应完整 ALE 方程消去规定材料自由度后的机械子系统，不能只保留 `2N_t q̇_e`。

质量矩阵随绳长变化。当 `ṡ_i=s̈_i=0`，`N_t=N_tt=0`，自动退化为固定材料网格 ANCF。绳质量为 `ρA L(t)`，质量流入/流出经过顶端。上方卷绕绳及卷筒不属于计算域，支撑/执行机构提供所需边界作用。

## 4. 轴向和弯曲弹性

沿用论文式 (8)–(10) 的能量度量：

```text
a=r_s=Bq_e, b=r_ss=Cq_e
ε=||a||-1
κ=(a_x b_y-a_y b_x)/(a^T a)
U_e = 1/2 ∫ [EA ε² + EI κ²] ds
Q_elastic = ∂U_e/∂q_e
```

κ 是论文选用的曲率度量，不是直接用 `cross(a,b)/||a||³` 定义的几何曲率。二维实现使用有符号 κ；因势能为 κ²，与论文绝对值形式等价，且避免绝对值在零点的导数问题。

弹性力采用解析能量梯度，积分使用八点 Gauss 积分。未加入绳内阻尼；结构阻尼仍为 `cB`。代码输出的 `EA ε` 是轴向本构力，不应称为包含弯曲剪力的完整端部反力。

当任一单元积分点轴向应变下降至零时，仿真事件停止，避免把梁模型的压缩分支解释成真实松绳。该检测限于积分点，未构建完整接触或松弛动力学。大摆角、曲线形状可被描述，但材料本构仍是线弹性。

## 5. 支撑、载荷与初值

顶端集总质量 mT，底端质点质量 mP，支撑力为 `-kB*d-cB*ḋ`。重力包含绳索分布重力及两端质量。机械自由度总数为 `4(N+1)`；默认三个单元，对应 16 个机械坐标、32 个一阶状态。通过共享坐标消去连接约束，采用 `ode15s` 的时变质量矩阵形式求解一阶 ODE，而非完整约束 DAE。利用单元连接关系给出稀疏 Jacobian 模式，并缓存只依赖网格状态的形函数与质量/惯性积分；状态相关的弹性力仍逐次计算。

初始直垂绳平衡形状可解析写出。设 `u=s+L0` 从顶端量起：

```text
d0=(mT+mP+ρA L0)g/kB
y(u)-d0=u+[mP g u+ρA g(L0 u-u²/2)]/EA
y_s=1+[mP g+ρA g(L0-u)]/EA
```

这是一个二次位置场，Hermite 单元可以精确表示。默认将该形状绕顶端旋转 3° 释放；此倾斜初态不是静平衡。小车施加平滑水平力，2–8 秒内把材料长度从 2 m 收至 1.4 m，演示至 12 秒。

默认 `ρA=0.1 kg/m, EA=20000 N, EI=0.02 N m²` 是独立有效参数。钢丝绳有效抗弯刚度不直接等于实心圆钢的截面惯性矩估值；本例不作材料识别。修改刚度或单元数后需要重新检查求解器精度。

## 6. 验证与结果含义

运行：

```matlab
addpath('matlab');
test_aleancf;
out=tower_crane_aleancf;
```

完整测试会依次运行多组收绳仿真，细网格与严格容差下可能耗时较长；只查看默认结果时直接运行 `tower_crane_aleancf`。

仅需基础 MATLAB；在 MATLAB R2026a 测试。图表功能要求 MATLAB R2020a 或更新版本。结果保存到 `report/aleancf/`。

测试包含：

1. 固定材料坐标下，形函数时间导数与有限差分速度/加速度一致。
2. 静止材料场在移动网格上的表示仍给出零材料速度、零材料加速度。
3. 固定长度时附加 ALE 惯性消失。
4. 轴向与弯曲弹性力分别与势能差分梯度一致。
5. 一致质量矩阵正定、对称，刚体平移质量等于 `ρA l`。
6. 分布自重下的直垂静平衡。
7. 固定长度、无外部输入且无阻尼时的机械能守恒。
8. 实际收绳工况完成、积分点保持张力，并出现非零 ALE 惯性。
9. 时间积分精度比较，以及 3、6、9 单元的吊物弦线摆角比较。

**变绳长是开放材料域，不能要求该域的机械能恒定。** 变长度工况没有实现完整的执行机构功率与边界能流审计；固定长度能量测试不能替代这一验证。质量流动运动学测试用于独立检查关键 ALE 惯性项。

输出 `theta` 是顶端到吊物的弦线相对竖直向下的角度。柔性绳各处斜率不同，因此它不是整条绳统一的局部角度。默认张力较大，曲线接近直线是可能的，并不表示弯曲自由度未启用。

默认保存 601 个等间隔输出点，主要用于观察低频吊物运动。它们不同于求解器内部自适应步长；高频轴向力可能欠采样。研究高频谱或峰值时应增加 `p.nOutput` 并检查采样收敛，报告中的最小轴向力仅指已保存时刻和积分点的采样最小值。

网格比较仅检查本例的吊物弦线摆角，并不证明高频绳振动、局部曲率和端反力都已收敛。尚未与论文全模型、其他独立 ALE 求解器或实验数据对照。

|---|---:|

## 7. 参数修改与后续扩展

```matlab
p=aleancf.parameters();
p.nElem=6;
p.EI=0.01;
out=aleancf.simulate(p);
```

下一阶段可以加入顶端变长度单元的拆分/合并及守恒状态投影，随后接入吊臂梁有限元、执行机构和消摆控制。完整重网格需要检查质量、动量与能量传递，不宜直接插入/删除节点而不验证。
