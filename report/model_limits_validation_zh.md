# 模型的四项验证

统一入口：在仓库根目录执行 MATLAB：

```matlab
addpath('matlab'); setup_paths;
result = validate_model_limits;        % 全部验证，含动态网格细化
% result = validate_model_limits(false); % 仅静力、频率与 ALE 极限
```

结果写入 `report/model_limits/`，包含 CSV 误差表及可复查的 MAT 状态。

## 1. 悬臂梁静力

以端部横向载荷 F=10 N 的孤立起重臂为基准，比较端部挠度 FL³/(3EI) 与端部转角 FL²/(2EI)。数值端部转角由模态形函数的一阶导数求得。保留 1、2、4、8、16 个模态，输出两项相对误差；16 模态误差均小于 2% 为预设检查条件。

此模型的塔身和起重臂使用连续梁模态展开，ANCF 单元用于吊索。因此梁静力验证细化的是模态数，吊索离散验证细化的是 ANCF 单元数。已有 `validate_continuum_structure` 另行检查塔身和起重臂在自重及吊重作用下的组合静力场。

## 2. 固定悬点、固定索长的单摆频率

固定索顶端的两个位置自由度，保留自由斜率；在重力拉伸平衡态附近对内力作中心差分，求无阻尼广义特征值问题。最低角频率与 √(g/L) 比较，单位 rad/s；频率 Hz 为角频率除以 2π。

分别检查原始弹性索参数与接近理想单摆的轻质、高轴向刚度、低抗弯刚度参数，均使用 3、6、9 个单元。原始模型含分布索质量、伸长和弯曲刚度，与质量集中于端点、不可伸长的理想单摆存在物理差异，不能要求误差严格为零。近理想参数的最终误差预设小于 0.5%。本项采用线性模态频率，尚未作时域自由摆动周期交叉验证。

## 3. ALE 极限

当 L̇=L̈=0 时，材料网格端点的速度和加速度均为零，形函数的 Nt、Ntt 为零，附加惯性 Q_ALE=ρA∫Nᵀ(2Nt v+Ntt q)ds 消失。检查使用非零节点速度，避免通过静止状态得到无意义的零值，并设置移动网格的非零对照。固定索长不会消除普通惯性 Mq̈。

## 4. ANCF 网格细化

固定塔身/起重臂各 4 个模态，对完整变索长工况采用 3、6、9、12 个索单元、共同输出时刻与积分设置。逐级比较：

- 吊荷二维位置差的最大欧氏范数（m）；
- 吊索下端轴向本构力 EA(|r_s|−1) 的最大差值（N）及相对峰值误差；
- 吊荷连接约束反力向量的最大差值（N）。

轴向本构力与含弯曲贡献的端部总牵引力分别报告，不能混称。末两级位置差小于 1 mm、轴向力相对峰值差小于 1% 时设置 meshPass=true；这只是所选工况下的工程判据，需同时观察各级误差走势。最细网格另用更严格积分设置重跑，输出吊荷位置的时间离散误差，以检查空间误差是否被时间误差掩盖。梁模态截断误差需独立验证。
